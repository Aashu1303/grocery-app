# 0006. App name Rasoi, package app.rasoi

Status: Accepted
Date: 2026-10-10

## Context
The name was an open choice in the kickoff prompt.

## Decision
The app is called Rasoi (Hindi for kitchen). Root package is `app.rasoi`; feature packages are `app.rasoi.feature.<name>`; the theme is `AppTheme` as the plan specifies.

## Consequences
Changing the name later means renaming packages and the application id.
