# Technology icon credits

The technology marks are from [Simple Icons](https://github.com/simple-icons/simple-icons), downloaded from its `develop` branch on 2026-10-15. The upstream project distributes these icons under [CC0 1.0](LICENSE.txt).

Local adaptations preserve the path geometry and add a colored fill and rounded light background so each mark stays visible in light and dark README themes. The Compose mark is the upstream Jetpack Compose icon, used here to identify the Compose UI family.

These marks identify technologies used by the project; they do not imply endorsement. Brand names and marks remain the property of their respective owners. Rasoi's own app icon is reused directly from the existing iOS asset catalog, as documented in ADR 0027.

Keep the SVGs self-contained: no scripts, external resources or embedded fonts. README labels and image alt text identify every technology without relying on color alone.
